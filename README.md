# AI Customer Review Intelligence System

An end-to-end NLP + Machine Learning system that analyzes Amazon customer reviews to extract sentiment, topics, and insights.

---

## 🚀 Project Overview

This project builds a complete pipeline to:

- Process and clean raw customer reviews
- Convert text into numerical features using TF-IDF
- Train machine learning models for sentiment classification
- Extract insights and patterns from review data
- Prepare for deployment using an interactive dashboard

---

## 🧠 Key Features

- Advanced NLP preprocessing (stopwords, lemmatization)
- TF-IDF vectorization with n-grams
- Stratified train-test split (no data leakage)
- Modular pipeline using `src/` structure
- Scalable and production-ready design
